# Changelog

Este arquivo registra as mudanças relevantes do Vue Template.

O formato segue o [Keep a Changelog](https://keepachangelog.com/pt-BR/1.1.0/) e as versões seguem o [Versionamento Semântico](https://semver.org/lang/pt-BR/).

## [Unreleased]

### Added

- Estrutura inicial com Vue 3, Vite, Tailwind CSS e ESLint.
- Docker Compose e imagem de produção com Nginx.
- Workflow do GitHub Actions para lint, build e testes de ponta a ponta.
- Teste da página inicial com Playwright e Chromium, executado contra o build de produção na CI.
- Configuração do `act` para executar a CI localmente.
